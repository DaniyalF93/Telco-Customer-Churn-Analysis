#End-to-End Customer Churn Prediction System
**This project builds classification models to predict customer churn and analyzes feature importance to understand the key factors driving churn.**

*Why do Customers decide to unsubscribe from a specific servidce ?*
*How do different models differ in results from each other ?*

*Data is Telco Customer Churn Data from Kaggle*

*Models tested:*
    ->Logistic Regression
    ->Naive Bayes
    ->Decision Tree
    ->XGBOOST



Tech stack:
    Python
    pandas / sklearn
    XGBoost or LightGBM
    Proper train/val/test split
    Threshold tuning
    Simple inference script

Files:
    ->data_checks.py
    ->train.py
    ->evaluate.py
    ->predict.py
    ->requirements.txt
    ->Dockerfile
    ->Makefile
